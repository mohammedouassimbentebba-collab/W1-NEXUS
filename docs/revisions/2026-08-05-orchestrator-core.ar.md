# مذكرة اعتماد Orchestrator Core — 2026-08-05

## القرار

اعتماد محرك تنسيق مرجعي يفصل بين:

- العقود القانونية وسجل `SessionStore`.
- الحالة التشغيلية القابلة للاستئناف في `OrchestratorJournal`.
- موصلات المزودين.
- بناء أغلفة المجال عبر `EnvelopeFactory`.

## القرارات المعمارية

1. الهدف يترجم إلى رسم مهام حتمي قبل أول استدعاء نموذج.
2. لا ينفذ أي Task قبل اكتمال اعتمادياته.
3. `SessionStore` هو المسار الوحيد لقبول الأغلفة المعيارية.
4. كل محاولة مزود لها idempotency key ثابت.
5. النتيجة المجهولة لدى مزود غير idempotent توقف التشغيل للمصالحة.
6. نفاد الحصة يحدث خطة الموارد بدل استعمال مورد منهك كأنه نشط.
7. السياق يقتصر على الحقول المصرح بها للمهمة.
8. نتيجة المزود يجب أن تطابق نوع المخرج المتوقع.
9. البديل الأضعف لا يمر من دون الإفصاح والمراجعة الإضافية المطلوبة.
10. دفتر البروتوكول لا يخزن أسرار السياق في أثر التشغيل المرجعي؛ يسجل أسماء الحقول فقط.

## نتيجة الاختبارات عند الاعتماد

- اختبارات مترجم الهدف وتشكيل الفريق.
- تشغيل كامل مع نفاد الحصة والتحويل إلى بديل.
- منع تسريب حقل سياق غير مطلوب.
- استئناف تشغيل مكتمل دون استدعاءات جديدة.
- توقف آمن عند نتيجة مزود غير مؤكدة وغير idempotent.
- حجب التشغيل عند استهلاك ميزانية استدعاءات الفريق.
- سلامة سجل `SessionStore` بعد أحداث المنظم.
