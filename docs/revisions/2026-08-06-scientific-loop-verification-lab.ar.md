# مذكرة اعتماد W1 Scientific Loop + Verification Lab

**التاريخ:** 2026-08-06  
**الحالة:** معتمد للتنفيذ المرجعي `dev30`

## القرار

اعتماد دورة علمية محلية قابلة للتدقيق تتكون من:

- سؤال بحثي وفرضية عدم.
- تنبؤات قابلة للاختبار.
- تسجيل مسبق بخطة ثابتة.
- تنفيذ عبر Secure Execution Fabric.
- ملاحظات Append-only.
- تحليل مخطط وتحليل استكشافي معلن.
- معايير دحض مسجلة مسبقًا.
- تكرار مستقل.
- مراجعة علمية مستقلة.
- حزمة إعادة إنتاج ذات Manifest وبصمات.
- جسر غير مزيف إلى W1-CIP Evidence وVerification.
- نشر صريح فقط إلى Memory Fabric.

## قرارات معمارية

1. لا يساوي التحليل الإحصائي قرارًا نهائيًا.
2. لا يسمح بتغيير الخطة بعد التسجيل المسبق داخل هوية الدراسة نفسها.
3. لا تضاف بيانات بعد بدء التحليل؛ تستخدم دراسة جديدة أو Replication.
4. لا يستطيع التحليل الاستكشافي إكمال معيار مخطط مسبقًا.
5. لا يستطيع منشئ الدراسة أو محللها اعتماد المراجعة النهائية.
6. لا تُنشأ كيانات W1-CIP ناقصة المراجع؛ يستخدم Bridge Manifest حتى تتوفر مراجع الجلسة.
7. لا تحفظ النتائج في الذاكرة تلقائيًا.
8. تبقى قيم `p` التقريبية موسومة بطريقة الحساب.
9. يرفض W1 حزمة إعادة إنتاج ذات ملفات إضافية غير معلنة.
10. لا يعتبر ذكر Randomization أو Blinding في JSON إثباتًا على التنفيذ الفيزيائي.

## اختبارات القبول

- التسجيل المسبق قبل الملاحظات.
- منع التحليل قبل البيانات أو تحت الحد الأدنى للعينة.
- منع إضافة البيانات بعد التحليل.
- سلسلة تجزئة للملاحظات والأحداث.
- منع تكرار Observation ID.
- تطابق أمر وProfile التجربة مع الخطة.
- فصل التحليل المخطط والاستكشافي.
- تقييم Supported/Falsified/Inconclusive.
- منع مراجعة المنشئ أو المحلل لنفسه.
- مقارنة تكرار مستقل.
- حزمة إعادة إنتاج ومراجعة بصماتها.
- نشر Finding مدعوم ومراجع فقط إلى Memory Fabric.
- Bridge Manifest يحافظ على البصمات ولا ينتحل كيان W1-CIP.
- تشغيل CLI وWheel خارج مجلد المصدر.

## حدود معلنة

لا يتضمن `dev30` مختبر أجهزة عامًا أو تحليلًا إحصائيًا تخصصيًا شاملًا أو واجهة Notebook رسومية أو توقيعًا خارجيًا موثوقًا. هذه خصائص لاحقة في W1 Nexus الكاملة.
