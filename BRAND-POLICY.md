# W1 Nexus™ Brand Policy

Status: project brand policy for the pre-registration phase. This document does not claim that W1 or W1 Nexus is a registered trademark or a registered company.

## Code and brand are separate

The W1 Nexus source code is licensed under the Apache License, Version 2.0. The software license governs copyright and patent permissions for the code. It does not turn third-party forks, services, or distributions into official W1 Nexus releases.

## Project identity

- Official project display name: **W1 Nexus™**.
- Reverse-DNS application identity: `com.w1.nexus`.
- URL scheme: `w1://`.
- Project file extension: `.w1nexus`.
- The `™` symbol is used only to identify the project name in this pre-registration phase; this repository does not claim a registered `®` mark.

## Descriptive use

It is appropriate to accurately state that another project is “based on W1 Nexus”, “compatible with W1 Nexus”, or “uses W1 Nexus”, provided the wording does not imply sponsorship, endorsement, or that the third-party product is an official W1 Nexus release.

## Forks and modified distributions

Forks and modified distributions may comply with Apache-2.0 while using their own product branding. They should not present themselves as the official W1 Nexus distribution unless the project maintainers have explicitly authorized that representation.

## Logo master

The selected geometric **W + 1** concept is preserved in `brand/reference/W1-Nexus-master-concept.jpeg`. It is a design reference, not the final production vector. Production assets must preserve the same core geometry and should not introduce a different emblem under the W1 Nexus name.

## Future registration

If the W1 organization/company and its marks are formally registered later, this policy can be updated to name the relevant legal owner and jurisdictions without changing the Apache-2.0 license already granted for covered code versions.
