# W1 Nexus Workspace + Live Operations Console

## الهدف

تحويل نواة W1 Nexus من مجموعة أوامر وخدمات خلفية إلى مساحة تشغيل بصرية موحدة تكشف ما يحدث فعليًا داخل النظام: الجلسات، الوكلاء، المهام، النماذج، الحصص، الذاكرة، الدراسات، التنفيذ الآمن، Git، الموافقات وسجل التدقيق.

هذه الخطوة ليست غلافًا تجميليًا حول CLI. الواجهة تقرأ مباشرة الإسقاطات الموثقة في قواعد W1 المحلية، وتستعمل بث Server-Sent Events لتحديث الحالة دون إعادة تحميل الصفحة.

## التشغيل

```bash
w1 --workspace ./project init
w1 --workspace ./project workspace serve
```

يفتح الخادم افتراضيًا على:

```text
http://127.0.0.1:8765/
```

يمكن تشغيله دون فتح المتصفح:

```bash
w1 --workspace ./project workspace serve --no-browser
```

ويمكن اختيار منفذ آخر:

```bash
w1 --workspace ./project workspace serve --port 9001
```

## أوضاع التشغيل

### القراءة فقط

هذا هو الوضع الافتراضي. يستطيع المستخدم:

- رؤية الحالة الحية.
- البحث والتصفية.
- فحص سلامة جميع الجلسات.
- استعراض النتائج والموافقات والذاكرة والدراسات.

ولا يستطيع تنفيذ عملية تغيّر الحالة.

### العمليات المسموحة

```bash
w1 --workspace ./project workspace serve --allow-operations
```

يفتح هذا الوضع عمليات محلية محدودة ومسموحًا بها صراحة، مثل إعادة بناء إسقاط جلسة أو تشغيل المثال المرجعي. لا يمنح الواجهة وصولًا عامًا إلى Shell، ولا يتجاوز Action Runtime أو الموافقات القانونية.

## أسطح الواجهة

### لوحة المشروع

تعرض مؤشرات الجلسات، التشغيلات، الوكلاء، الموافقات، الذاكرة، الدراسات، الـSandbox والأدوات، إضافة إلى صحة كل مكون.

### الرسم الحي للوكلاء

يقرأ مهام Orchestrator وتشغيلات Parallel Runtime، ويعرض الحالة والمورد والمحاولات والحاجة إلى مراجعة إضافية.

### مراقب النماذج والحصص

يعرض الموارد المسجلة في `ExecutionResourcePlan` وملاحظات المزود، مع الحالة والحصة والاحتياطي وموعد إعادة الضبط حيث تتوفر البيانات.

### مركز الموافقات

يجمع الموافقات غير المستهلكة من Action Runtime وUnified Tool Registry. تبقى الموافقة القانونية مرتبطة بالبصمة وذات استعمال واحد؛ الواجهة لا تحولها إلى زر عام غير مقيد.

### Memory Inspector

يعرض المراجعات الحالية فقط مع النوع والثقة والتصنيف والرؤية، ويكشف عدد التعارضات المفتوحة مع بحث محلي داخل البيانات المعروضة.

### Scientific Notebook

يعرض الدراسات وحالة التسجيل المسبق وعدد الملاحظات والتحليلات ونتيجة آخر مراجعة علمية.

### Git + Merge Review

يعرض الفرع الحالي والتغييرات غير المثبتة وآخر الـCommits ومقترحات الدمج والاختبارات والمراجعات المرتبطة بها.

### Sandbox Telemetry

يعرض Backend وProfile والحالة والمدة وPeak RSS وعدد Artifacts لكل تنفيذ مسجل.

### Audit Explorer

يجمع موجزًا زمنيًا من ProtocolEvent وParallel Runtime وAction Runtime وScientific Loop دون تعديل السجلات الأصلية.

## البنية التقنية

تستعمل الواجهة:

- `ThreadingHTTPServer` محليًا دون Framework خارجي.
- HTML وCSS وJavaScript مضمنة داخل Wheel.
- REST snapshot موحدًا.
- Server-Sent Events للبث الحي.
- SQLite بوضع القراءة فقط لبناء الإسقاطات.
- عمليات محدودة تمر عبر طبقات W1 الأصلية.

لا تعتمد الواجهة على CDN أو خطوط أو سكربتات خارجية، ويمكن تشغيلها دون اتصال بالإنترنت.

## الحماية

- الارتباط محصور على loopback: `127.0.0.1` أو `localhost` أو `::1`.
- رفض الربط على `0.0.0.0`.
- Token محلي عشوائي محفوظ بصلاحية `0600` على POSIX.
- جميع API تحتاج Bearer Token، وبث SSE يحتاج Token أيضًا.
- التحقق من Host لمنع شكل من DNS rebinding.
- لا توجد CORS مفتوحة.
- Content Security Policy تمنع المصادر الخارجية والإطارات.
- الوضع الافتراضي للقراءة فقط.
- لا تُعرض قيم مفاتيح API أو الأسرار.

## Snapshot آلي

يمكن تصدير الحالة دون تشغيل الخادم:

```bash
w1 --workspace ./project workspace snapshot \
  --output .w1nexus/reports/workspace-snapshot.json
```

ينتج Snapshot منقحًا يحمل `snapshot_digest` ثابتًا لمحتواه.

## الحدود الحالية

الخطوة 31 تقدم Workspace ويب محلية كاملة المراقبة، لكنها ليست بعد تطبيق سطح مكتب Native. لم يكتمل بعد:

- Electron أو Tauri shell مع مثبت Windows/macOS/Linux.
- محرر كود ومقارنة Diff بصري متقدم.
- تحرير المستندات والجداول والعروض داخل الواجهة.
- Terminal تفاعلية محكومة داخل المتصفح.
- Computer Use بصري.
- تعاون متعدد المستخدمين ومزامنة خادم مركزي.
- إشعارات النظام والمهام المجدولة.
- مصادقة حسابات متعددة؛ النسخة الحالية محلية لمستخدم الجهاز.

هذه الحدود مقصودة، والخطوة التالية ستبني طبقة Artifact Studio وDesktop Shell فوق الأساس الحالي بدل إعادة كتابة الواجهة.
