# مذكرة اعتماد: Parallel Multi-Agent Runtime + Merge Coordinator

التاريخ: 2026-08-05

## القرار

اعتماد تشغيل الوكلاء المتوازيين كطبقة مستقلة فوق Action Runtime وGit، مع منع الدمج المباشر من الوكلاء.

## القرارات الملزمة

- كل وكيل نشط يملك Worktree وفرعًا مستقلين.
- رسم الاعتماديات يجب أن يكون لا دوريًا.
- المسارات المشتركة المعلنة تستخدم أقفالًا استشارية متداخلة.
- نتائج كل وكيل تُثبت في commit مستقل مع هوية مؤلف واضحة.
- Merge Proposal يبنى من base commit مثبت.
- الاختبارات تعمل داخل Integration Worktree قبل مراجعة الدمج.
- المراجع لا يكون من الوكلاء المنتجين.
- الدمج النهائي يحتاج موافقة بشرية ويستخدم fast-forward فقط.
- تقدم الفرع الهدف يبطل قابلية تطبيق المقترح القديم.
- التعارض أو فشل الاختبارات لا يعدل الفرع الهدف.

## السبب

التوازي غير المحكوم يزيد السرعة ظاهريًا لكنه يخلق كتابة متضاربة، مراجعة ذاتية، ودمجًا يصعب التراجع عنه. الفصل بين الإنتاج والتكامل والمراجعة يجعل الزيادة في السرعة قابلة للتدقيق ولا تخفض جودة القرار.

## المؤجل

- تشغيل موزع متعدد الأجهزة.
- حاويات أو VMs لكل وكيل.
- استئناف آلي بعد انهيار عملية الوكيل.
- مراجعة دلالية آلية للـdiff.
- استراتيجية دمج جزئي عند فشل أحد الفروع.
- إدارة عمر worktrees والفروع تلقائيًا.
