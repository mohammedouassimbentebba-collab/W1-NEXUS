# مذكرة مراجعة الحوكمة — 2 أغسطس 2026

## سبب المراجعة

أظهرت مراجعة وثائق التأسيس أن الرؤية والنطاق كانا مناسبين للبدء، لكنهما لم يحددا بما يكفي معنى الدليل، وسلطة القرار، ودورة الاعتراض. كما بقيت حدود التحقق والمراجعة، وتشكيل الفريق، ومشاركة سياق المستخدم، وسجل الأحداث غير مكتملة.

## التعديلات الجوهرية

| المجال | قبل المراجعة | بعد المراجعة |
|---|---|---|
| القرار | كيان بلا دورة اعتماد مفصلة | دورة حالات، سلطة صريحة، أدلة، اعتراضات، وتراجع |
| الدليل | مصدر أو وسم بعدم التحقق | أنواع وعلاقة بالادعاء وسلامة وقيود |
| الاعتراض | شدة وإجراء مطلوب | دورة حياة وسلطات إغلاق مستقلة |
| التحقق والمراجعة | متداخلان جزئيًا | كيانان بوظيفتين ونتائج منفصلة |
| بطاقة الوكيل | قدرات وحدود عامة | أدوات وصلاحيات وسياسة بيانات وأدوار وتكلفة |
| تشكيل الفريق | توجيه بحسب القدرة | `TeamPlan` مبني على المخاطر والتحقق والميزانية |
| حالة المهمة | حالات انتظار متعددة محتملة | فصل `phase` عن `status` و`block_reason` |
| سياق المستخدم | غير محدد | منح سياق محدودة بالغرض والحقول والمدة |
| سجل التشغيل | غير قابل للتعديل أثناء التشغيل | أحداث `append-only` متسلسلة وحالة مشتقة |
| سيناريو العرض | مهمة هندسية عامة | حالة اصطناعية لاكتشاف خطأ هامش تيار البدء |

## الأثر في نطاق الإصدار

لم يضف التعديل تحكمًا رسوميًا أو ذاكرة طويلة المدى أو ثقة تشفيرية. أضيفت فقط الكيانات والقواعد اللازمة كي يكون `v0.1` بروتوكول حوكمة قابلًا للاختبار، لا مجرد تنسيق لتبادل الرسائل.

## مسائل ما زالت مؤجلة

- التوقيع والتحقق من الهوية بين المؤسسات.
- مقياس موحد لمعايرة ثقة النماذج.
- سياسة مثلى لتشكيل الفرق؛ السياسة الحالية خط أساس تجريبي.
- أوزان عامة لقوة أنواع الأدلة؛ السياق وطريقة التحقق يمنعان ترتيبًا ثابتًا صالحًا لكل المجالات.
- ضمانات الاستخدام في القرارات الطبية أو الصناعية أو القانونية.
