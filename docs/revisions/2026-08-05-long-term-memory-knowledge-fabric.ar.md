# مذكرة اعتماد Long-Term Memory + Knowledge Fabric

**التاريخ:** 2026-08-05  
**الحالة:** معتمد للتنفيذ المرجعي `dev29`

## القرار

اعتماد طبقة ذاكرة محلية محكومة تجمع بين:

- سجل مراجعات append-only.
- Provenance لكل مراجعة.
- ACL لكل ذاكرة.
- فصل إلزامي بين Namespace وProject.
- تعارضات صريحة غير محسومة آليًا.
- Validity وStaleness.
- بحث منظم وFTS ومتجه محلي ورسم معرفي.
- حزم سياق محدودة التوكنات ومصحوبة بمراجع.
- تكامل دقيق مع Orchestrator للحقول المطلوبة فقط.

## قرارات معمارية

1. لا تصبح مخرجات النموذج ذاكرة دائمة تلقائيًا.
2. لا يسمح باسترجاع عابر للمشاريع بصورة افتراضية.
3. لا يحسم تعارض القيم بحسب حداثة السجل أو عدد المصادر وحده.
4. لا يعد hashed vector بديلًا مكافئًا لـEmbeddings الدلالية.
5. لا تعيد المراجعة كتابة التاريخ؛ تضيف مراجعة جديدة.
6. تبقى الذاكرة منفصلة عن SessionStore لأن دورة حياتها تتجاوز جلسة واحدة، مع سجل Integrity مستقل.
7. يملك سياق المستخدم الحالي أولوية على الذاكرة القديمة.
8. لا يرسل Orchestrator إلا الحقول المذكورة في `required_context_fields`.

## اختبارات القبول

- عزل المشاريع.
- ACL خاصة وفريقية.
- إنشاء تعارض ومنع الاسترجاع الصامت.
- حل التعارض وإبقاء الخاسر في التاريخ.
- انتهاء صلاحية السجل.
- استبعاد الذاكرة القديمة افتراضيًا.
- البحث الهجين وتوسع الرسم.
- حدود التوكنات وحفظ Citations.
- كشف العبث في سلسلة الأحداث والمراجعات.
- ملء حقل Orchestrator من الذاكرة دون تسريب حقل غير مطلوب.
- تشغيل أوامر CLI من نسخة Wheel مثبتة خارج المصدر.

## حدود معلنة

لا يتضمن `dev29` تشفيرًا داخليًا عند السكون أو KMS، ولا Embedding سحابية افتراضية، ولا مزامنة موزعة. يجب عدم تقديم هذه الخصائص على أنها مكتملة.
