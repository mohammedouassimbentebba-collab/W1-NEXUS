# مذكرة اعتماد MCP وUnified Tool Registry — 5 أغسطس 2026

## القرار

اعتماد طبقة `MCP 2025-11-25 + Unified Tool Registry` كجزء أساسي من الرؤية الكاملة لـW1 Nexus.

## القرارات المعمارية

1. دعم `stdio` للعميل والخادم لأنه المسار المحلي الأبسط والأقل تعرضًا للشبكة.
2. دعم Streamable HTTP من جهة العميل مع فرض HTTPS للخوادم البعيدة.
3. عدم اعتبار annotations القادمة من خادم MCP مصدرًا للثقة أو الإعفاء من الموافقات.
4. Namespacing لكل أداة بعيدة بصيغة `mcp.<server_id>.<tool_name>`.
5. التحقق من `inputSchema` قبل الاستدعاء ومن `outputSchema` عند وجود `structuredContent`.
6. جعل `call_id` حتميًا وقابلًا لإعادة المحاولة دون مضاعفة الأثر.
7. تطبيق موافقة محلية HMAC، مرتبطة ببصمة الاستدعاء، ذات استعمال واحد.
8. عدم تخزين قيم المفاتيح؛ تخزن مراجع متغيرات البيئة فقط.
9. إبقاء W1 Action Runtime صاحب القرار النهائي في أفعال الملفات والأوامر، حتى عند استدعائه عبر MCP.
10. تطوير هذه الطبقة باتجاه W1 Nexus الكاملة، لا تجميدها عند حدود CLI أو MVP.

## النتيجة

أصبح W1 قادرًا على استهلاك خوادم MCP، عرض أدواته كخادم MCP، وتوحيد الأدوات المحلية والبعيدة تحت سجل وسياسة واحدة.
