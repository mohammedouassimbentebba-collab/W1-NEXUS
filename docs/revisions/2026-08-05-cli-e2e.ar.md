# مذكرة اعتماد CLI والتجربة الطرفية — 2026-08-05

## القرار

اعتماد واجهة `w1` كواجهة التشغيل المرجعية الأولى لـW1-CIP v0.1.

## القرارات المعمارية

1. استخدام مكتبة Python القياسية لـCLI لتقليل الاعتماديات.
2. فصل stdout للنتيجة عن stderr لبث الأحداث.
3. دعم JSON ثابت لكل الأوامر.
4. عدم تخزين قيم مفاتيح API.
5. حفظ بيانات استئناف التشغيل دون نسخ السياق أو الأسرار.
6. قراءة سلطة Runtime من إعداد مساحة العمل بدل تثبيتها داخل الكود.
7. تضمين مخططات البروتوكول داخل Wheel.
8. توفير وضع plan لا يستدعي النماذج.
9. توفير append/replay/rebuild/verify للسجل.
10. توفير benchmark داخلي للثوابت، مع منع تسميته مقارنة خارجية.

## قرارات السلامة والجودة

- لا يُسمح للتقدم المرئي بكسر التشغيل القانوني؛ أخطاء listener غير سلطوية.
- لا تعني إعادة التشغيل إعادة تنفيذ طلب مكتمل.
- لا تُطبع الأسرار في inventory أو doctor.
- لا يُعلن التفوق الشامل على أدوات أخرى دون Benchmark خارجي.
- التجربة المرجعية تركيبية ولا تمثل اعتمادًا هندسيًا لمنتج حقيقي.
