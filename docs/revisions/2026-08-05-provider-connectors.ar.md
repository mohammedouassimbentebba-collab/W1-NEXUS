# مذكرة اعتماد Provider Connectors — 2026-08-05

## القرار

اعتماد طبقة موصلات قياسية تعتمد بروتوكول `ProviderAdapter` الموجود في `OrchestratorCore`، مع نقل HTTP قابل للحقن وعقد JSON موحد للمخرجات.

## قرارات الأمان

1. تخزين مرجع السر فقط، وقراءته وقت الاستدعاء.
2. عدم تسجيل رؤوس المصادقة أو قيمة المفتاح.
3. HTTPS إلزامي للوجهات البعيدة.
4. HTTP المحلي يحتاج إذنًا صريحًا وعنوان loopback.
5. عدم اعتبار معرّف الطلب ضمان idempotency.
6. فصل حد المعدل المتجدد عن نفاد الحصة أو الرصيد.
7. اعتبار مهلة الاستجابة بعد الإرسال نتيجة مجهولة.
8. رفض أي مخرج لا يطابق عقد المهمة قبل تثبيته.

## قرارات التكامل

- حفظ الاستهلاك الفعلي في `ProviderResponse.metadata`.
- حفظ ملاحظات الحدود في `OrchestratorJournal.provider_quota_observations`.
- بقاء خطة الموارد مسؤولة عن الميزانية المحلية والاحتياطي.
- يستطيع `OrchestratorCore` التحول من مورد محدود مؤقتًا إلى بديل دون إعلان الحصة الشهرية منتهية.

## التوافق

أضيفت موصلات OpenAI Responses وAnthropic Messages وGemini Interactions وGemini generateContent وOpenAI-compatible. لا توجد مكتبات SDK إجبارية؛ يعتمد التنفيذ المرجعي على مكتبة Python القياسية.

## ما أُجل

التدفق، الأدوات متعددة الجولات، وسائط متعددة، تقارير الإنفاق الإدارية، Vault خارجي، وتسعير حي.
